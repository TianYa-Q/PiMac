# 定时任务与 extension 流处理优化

## Pi Mac

- 定时任务新增「正在派发」筛选与启用／暂停／派发中／失败概览。
- 支持按标题、即将执行、最近派发排序，并记住排序选择。暂停任务、缺失／无效日期排到即将执行列表末尾；同名任务以 ID 稳定排序。
- 刷新支持 ⌘R；确认框显示任务标题；编辑／确认期间不自动轮询，避免背景刷新干扰操作。
- 编辑、删除、启用／暂停、立即执行先读取最新 Server 列表，核对任务身份与配置。任务被删除或配置变化时不发送修改，要求刷新并重新打开编辑／确认。
- 配置比较包括项目、会话绑定、模型选项、工作区和访问策略，但忽略运行次数与派发时间等遥测。正在派发的任务不重复执行。
- 单个操作锁覆盖核对、修改、刷新全过程。核对读取失败明确提示「未发送修改」；修改结果未知仍不自动重试。
- 无效日期显示「—」，不再显示遥远过去的日期。

**边界：** 这是客户端操作前核对，不是 Server 原子 compare-and-swap。其他客户端仍可能在核对之后、修改之前变更任务。没有引入私有 Server 协议，也不声称消除了这段竞态。派发成功仍不代表模型执行完成。

## account-usage

- 抽取共享采样新鲜度策略，供健康检查和额度文本显示使用。JSON doctor 协议保持 version 1、不增加账户身份或错误正文。
- TUI 状态栏明确警告过期、时间未知及系统时钟超前；额度摘要显示实际采样年龄，空窗口显示「额度未知」。运行中使用 60 秒、空闲使用 180 秒阈值。
- HTTP 清理立即发起取消并释放 reader 锁，但不等待底层不可信的 cancel Promise。错误响应、超大响应和取消请求不会因为挂起的清理阻塞返回／重试。
- 并发映射保留实际最早发生的失败，而不是按 worker 输入顺序选择错误；仍停止排队工作、等待活动 worker 完成并优先保留取消原因。

## 验证与限制

运行 `./scripts/check.sh`，包括 Swift 格式检查／测试、开发 watcher 测试、extension 类型／lint／格式／测试、真实本地 Pi RPC 兼容性与 T3 sidecar 检查／测试。

新增回归覆盖未轮询的外部配置修改、已移除任务、运行中拒绝重复派发、核对期间重复点击、日期排序、采样边界／未知／未来时间、不结束的流清理，以及失败发生顺序。

测试使用临时目录、合成凭据和本地 fixture；未进行真实付费额度查询或人工 GUI 验收。加载 extension 更新需重启 Pi／重新连接会话；不要为更新中断正在执行的任务。
