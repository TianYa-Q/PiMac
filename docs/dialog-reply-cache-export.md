# 扩展回复与离线额度导出优化

## PiMac

- 扩展回复在 coordinator 边界校验类型和内容：选择只能返回原始选项，确认必须返回 Bool，输入必须返回文本；不允许同时发送值、确认和取消。非法回复不会关闭对话框或消费队列。
- 输入／编辑回复限制为 256 KiB UTF-8，与请求预算一致；边界以字节而非字符计算。编辑器显示实时字节计数，超限禁用提交；Return 路径同样校验，不截断文本。
- 输入支持 ⌘Return 提交。取消已修改的文本会询问是否放弃；确认授权弹窗仍无 Return 授权快捷键。
- 本地 presentation UUID 隔离保持不变。请求在 Server 过期或会话被关闭时仍自动移除；放弃确认不是持久化草稿，不能阻止 Server 超时。

## account-usage

- `/usage cached` 现在按可见账户列出缺失快照，即使部分账户已有额度也不会隐藏缺失项。
- `/usage cached json` 经通知通道输出 version 1 白名单快照：provider、生成时间、账户名、当前账户标记、状态、采样新鲜度及原始采样时间、额度窗口。resetAt 保持 Unix 秒，capturedAt / generatedAt 为 Unix 毫秒。
- JSON **包含账户名称**，但不含凭据、账户 ID、原始错误、reset-credit 标题或隐藏账户。分享前检查名称；只需计数诊断时使用 `/usage doctor json`。
- 导出与文本展示均只读取当前会话可见、身份匹配的缓存，不请求网络、不预热、不轮换账户、不读取其他进程缓存；后台刷新照常。通知可能被无 UI 客户端忽略。
- HTTP body / reader 清理同时隔离同步抛错与异步拒绝。清理失败不覆盖 HTTP 错误、JSON 解析错误、成功结果或会话取消；挂起清理仍不会阻塞返回。

## 验证

新增原生回复类型／预算／队列回归测试、离线 JSON 白名单和缺失账户测试、真实命令路径的无网络／无凭据变更及重新登录身份失效测试、抛错 reader 清理测试。

本轮执行 Swift 全量测试、扩展全量测试和类型／格式／lint 检查。登录、真实额度接口权限及 SwiftUI 交互观感仍需实机验收；未调用付费模型。
