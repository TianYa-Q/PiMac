# 额度面板与跨端快照优化

## PiMac UI 与展示重构

- 展开额度卡后可搜索账户名称，筛选「全部／未隐藏／需关注」，按名称、剩余额度、即将重置排序；支持一键清除筛选和结果计数。
- 当前账户在匹配结果中置顶。剩余额度按两个窗口的较低值降序；隐藏、失败、过期、未知或时钟异常的额度排到末尾，不能用旧快照推荐账户。
- 重置排序忽略已过去的日期；同值按账户名稳定排序。Gemini 独立显示在账户列表之后，同样支持搜索与需关注筛选。
- 「需关注」包括失败、缺失额度、采样过期／未知／时钟异常及低于 20% 的窗口；隐藏账户不计入此筛选。这是展示规则，不改变自动轮换阈值或账户设置。
- 记住展开状态与排序。错误正文可通过悬停查看，折叠按钮、筛选和搜索补充无障碍标签。
- 将筛选与排序提取为不依赖 SwiftUI／网络的 `AccountQuotaPresentation`，保持额度卡的 equatable 更新隔离；分钟级时间线让采样过期后自动进入需关注列表。

## Gemini 采样时间贯通

- extension 实际查询成功时记录 `capturedAt`，共享缓存和 RPC 原样传递。宿主只读额度查询的 summary 和 per-model fallback 也记录实际完成时间。
- 原生 Gemini 行与 TUI 现在显示采样新鲜度；发布时间不能替代查询时间。旧快照缺少时间仍兼容，但显示未知。
- 原生模型转换保留时间；外部非法时间转换为未知，extension 缓存中显式非法时间拒绝复用。
- 新字段保持现有 version-2 状态协议兼容，未修改 doctor version-1 JSON 协议。

## 稳定性

- extension 的 Antigravity 认证读取和查询共用 15 秒等待上限，可由会话取消提前结束。超时返回查询失败，旧任务的迟到结果不能继续应用；迟到 rejection 被观察，不变成未处理异常。
- **限制：** 外部 Antigravity adapter 不支持 AbortSignal，无法保证超时后其底层 I/O 已终止；等待上限不等于网络强制终止，也没有增加自动重试。
- 宿主额度接口统一使用有界 JSON reader：实际字节限制 256 KiB、几何扩容、严格 UTF-8／对象结构校验。大量细碎分块不会导致每块对象长期留存。
- 请求取消关闭挂起读取，立即释放 reader；HTTP 错误／超大响应清理不等待不可信 cancel Promise。清理错误不覆盖原始请求错误。

## 验证

新增回归覆盖搜索、筛选、活动账户置顶、过期额度降权、重置时间／稳定排序、Gemini 查询时间投影与缓存复用、异常时间、永不完成的认证读取、取消和迟到 rejection、碎片 UTF-8、实际字节上限及永不完成的流清理。

测试只使用本地 fixture 和临时凭据目录，不进行真实付费额度查询。人工 GUI 与真实上游授权仍需验收。更新 extension 需重启 Pi／重新连接；不要中断正在执行的任务。
