# PS5 网关

设置 → PS5 网关是原生会话界面：自动只读检查、系统授权开启、应用内停止、显示局域网网关地址、折叠使用须知与诊断。不启动 Terminal，不保存密码，不安装服务或 sudoers 规则。

## 状态与生命周期

- 环境就绪：FlClash 核心与 TUN 检查通过，IPv4 转发未被其他服务占用。
- 等待授权 / 正在启动：不当作已运行。开始前必须完成环境检查。
- 网关运行中：只有 root 守护进程在检查 TUN 身份与 sysctl 后发布的新鲜 `active` 状态才显示绿色。
- 正在恢复：删除应用租约后，等待守护进程真正恢复并发布 `stopped`，不是点击停止即宣布成功。
- 状态过期、缺失或损坏：立即撤销绿色状态；确认超时则请求停止并显示错误，不假定已经恢复。
- 运行中只证明本机网关参数被确认，不证明 PS5 已连接、UDP 游戏正常或无旁路。

应用每秒刷新当前会话的租约。守护进程检查应用 PID 和租约（12 秒有效期），应用退出、崩溃、TUN 变化或租约删除后尝试恢复。正常退出先等待恢复确认；确认失败会暂停退出并提示。开发重载在网关会话及管理员授权期间被阻止，避免静默中断游戏。休眠可能结束会话，恢复后需重新开启；不自动重启或再次授权。

## 权限边界

使用 `osascript` 的 `do shell script ... with administrator privileges` 系统弹窗。管理员进程执行从打包资源捕获的不可变 Python 代码快照：`/usr/bin/python3 -I -u -c ...`，不以 root 身份加载用户可改的模块或脚本路径。启动前先编译快照，缺少 Python 或语法错误会由授权命令返回。

root 状态写入新建的 `/private/var/run/pimac-ps5-<UUID>`，从不向用户租约目录写文件，也不复用既有状态目录。状态原子发布；结束后保留 30 秒供 UI 读取，随后清理。root 只读取用户的心跳，使用 `O_NOFOLLOW` 并检查文件类型、属主、时间。停止只删除自己的心跳，不需要第二次授权，不向 PID 发送任意 root 信号。

原脚本的 root 独占锁、已开启转发拒绝接管、仅恢复自己修改的值等保护保留。失败日志折叠在诊断区。强杀守护进程、系统崩溃与恢复命令失败仍无法保证恢复；不是 VPN kill switch，也不安装 NAT、防火墙或 PS5 白名单。

## 测试

不修改系统参数、不触发管理员弹窗：

```sh
swift test --filter PS5GatewayCommandTests
PYTHONPATH=Sources/PiMacApp/Resources/ps5-gateway /usr/bin/python3 -m unittest discover -s Tests/PS5Gateway -v
```

覆盖：内置代码快照编译、参数转义、状态新鲜度、租约缺失/过期/属主/符号链接、启动前过期、TUN 变化、状态发布失败时仍恢复、恢复失败不报成功。管理员授权、实机 PS5 UDP 和 macOS UI 仍需人工验证。
