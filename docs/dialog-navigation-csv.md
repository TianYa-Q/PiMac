# 原生扩展导航与安全 CSV 导出

## PiMac：交互与请求边界重构

- 普通 select 弹窗从即时发送按钮改为原生单选 List。先选择，再点击“提交选择”或按 ⌘Return；List 获取焦点后支持系统方向键导航。没有默认选择，普通 Return 不提交授权。
- 大于 8 个选项时显示搜索框、匹配数量和清除按钮。修改搜索会清除选择；单个搜索结果也不会自动提交。空列表与搜索无结果有独立提示。
- 保留原始顺序、重复标签的索引身份及完整 wire value；不截断选项。专用账户管理／可见性弹窗保持原有行为。
- 请求解码提取为 ExtensionDialogRequest。select 必须有字符串数组（允许显式空数组）；提供的文本字段必须是字符串。缺省文本保留原有兼容行为。请求 ID 非空且最多 1024 UTF-8 字节，弹窗继续遵守 256 KiB／4096 选项预算。
- 非法请求发送取消，不入队；重复检查在解码之前进行，避免畸形重发取消已展示的正常请求。presentation UUID 与来源会话隔离仍然有效。
- 普通状态每会话最多 64 个键，键最多 256 字节、原始文本最多 16 KiB；超限拒绝而非截断，已有键仍能更新和清除，清除后释放容量。类型错误不误清已有状态。账户 GUI 快照保留独立的 1 MiB 限制，不受普通状态文本预算影响。

## account-usage：/usage cached csv

与 cached/json 共用 buildCachedReport：只读取当前会话可见、身份匹配的缓存，列出 available、failed、missing 状态及 fresh/stale/future/unknown 新鲜度。没有网络、预热、账户轮换、凭据变更或自动文件写入；正常后台刷新不停止。

输出走通知通道，可复制保存为 CSV；无 UI 客户端可能忽略通知。列含 provider、生成时间、账户名称、当前账户标记、状态、采样时间、主／次额度窗口。时间列用 _ms / _s 明示单位，缺失值留空，失败快照不导出旧窗口。空账户集合仍有表头。

CSV 使用 CRLF、双引号转义，支持逗号、多行和 Unicode 名称。账户名以 =、+、-、@ 开头（包括前置空白／控制字符）的文本会添加单引号，避免常见表格公式注入；因此受保护名称不是原名称的逐字节副本。JSON 导出保持原始名称。CSV **仍包含账户名**，分享前检查；不包含凭据、账户 ID、隐藏账户或原始错误。不要将此措施当作所有第三方表格导入器的安全保证。
