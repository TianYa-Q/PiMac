# 桌面 HTML 预览

## 实时加载与缓存

HTML 工具完成后，当前打开会话的快照 hydration 会使用官方签名附件接口下载页面，并在交给视图之前缓存文档。不需要重新打开会话。文档缓存位于 `T3DesktopClient` 内存中，附件不可变，总预算 16 MiB，单文档下载上限 8 MiB；不是跨应用启动的磁盘缓存。网页的远程资源仍遵循 WebKit 非持久站点存储的生命周期。

快照先于详情或附件持久化到达时，缺失输出不能当作合法空页面。已有快照引用优先直接下载；详情中已解析出的引用在失败后保留。前三次随轮询重试，随后降频为 10 秒，失败不会提交已完成的线程 revision，从而允许当前会话自动恢复。每轮详情读取预算仍为 8 条。

## 图片放大

点击 HTML 中的图片会打开较大的原生预览面板，可用双指缩放并滚动查看。预览使用独立、非持久的 WebKit sandbox，不借用 Server 网络会话、凭据或本地文件权限。

只接受有界的 HTTP(S) 图片 URL 或明确的图片 data URI；拒绝 file URL、自定义协议和含用户名/密码的 URL。blob 图片由原页面在自己的权限范围内转为有界图片数据。图片源长度上限 16 MiB，HTTP(S) URL 上限 8192 字节。图片加载失败显示明确错误，不静默留白。

## 滚动

保留现有预览窗口高度计算。移除原生滚轮监视器、页面滚动边界探测及向外层会话直接转交滚轮的逻辑。HTML 页面及内部滚动区域使用 `overscroll-behavior: contain`，不再进行链式滚动。

## 回归

- `HTMLLiveHydrationTests`：缺失详情/输出、下载失败后引用保留、失败恢复、读取预算及合法工具失败。
- `HTMLRenderDeliveryTests`：真正的 Server live hydration 在任何手工读取之前完成缓存，移走测试附件后仍可读取。
- `HTMLRenderImageTests`：图片源安全边界、脚本转义、真实 WebKit 鼠标点击、滚动隔离和原生缩放配置。
- 临时图片预览截图测试还验证了实际 WebKit `magnification == 2`；相关代码及截图留在 `tmp`。
