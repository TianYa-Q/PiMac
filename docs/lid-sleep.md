# 插电合盖运行：会话与恢复

## 生命周期

- `requested` 是用户意愿，持久化保存；`phase` 是唯一的执行阶段，`enabled` / `busy` 由它派生。失败不撤销用户意愿。
- 每次开启创建独立的临时目录和 `lease` 文件。helper 独立检查租约、应用 PID 和进程启动时间；UI 定时器只读状态，不再每秒续租。
- 主线程卡顿、App Nap、系统睡眠导致的 UI 调度空档不会让 helper 自行退出。应用退出/崩溃或租约撤销时，helper 恢复 `disablesleep 0`。
- helper 每轮检查实际电源及 `SleepDisabled`，不相信睡眠前的缓存。未知电源/读取失败是错误，不当成电池模式。仅插电且合盖时请求屏幕休眠。
- 开启前要求系统原本允许休眠；不接管已经被其他工具禁用的休眠设置。仍不应与其他防休眠工具同时使用。

## 观测与恢复

- `pid`、`state`、`exit` 用临时文件 + rename 发布，避免观察者读到截断/空文件。
- 状态文件过期但 helper 仍存活，只显示连接恢复中，不删除租约、不启动第二个 helper。
- helper 结束或 PID 已不存在时，记录退出原因、原命令错误和恢复结果。`owned` 只在确认原始系统设置后写入，用于识别本会话可能修改过的开关。
- 仅免密码会话自动恢复；不会在后台追加管理员授权弹窗。异常退出未完成恢复时，先凭当前会话的所有权记录恢复休眠，再重新检查权限及系统设置并创建全新会话。
- 自动重建退避为 2 / 5 / 15 秒，最多三次。预算跨重建保留，健康运行一分钟后重置；权限/启动失败不会无限重试。失败后仍可手动重试。
- 所有异步开启/恢复都有 generation 和取消检查，关闭后旧任务不能重新开启会话。租约清理失败时保留会话引用，不允许新会话覆盖它。
- 恢复系统设置不依赖日志目录存在：即使应用已删除租约目录，EXIT trap 仍执行 `pmset`。日志写入失败不能阻止恢复休眠。

## 权限与边界

免密码 helper 本身不提权，仅两个精确的 `pmset -a disablesleep 0/1` 命令使用已有 sudo 权限。临时管理员授权模式继续使用内联脚本，不让 root 读取用户可写的脚本；不安装常驻系统服务。

这不是系统级服务：helper 被强杀且应用也无法运行时，不能保证自动恢复全局开关。手工恢复命令为 `sudo pmset -a disablesleep 0`。对仍存活但卡住的 helper 不并发接管，以免两个会话交错覆盖系统设置。

## 验证

`swift test --filter LidSleep` 覆盖租约撤销、应用退出/PID 复用、无 UI 心跳运行、插拔电、真实设置被重置、查询/设置/恢复失败、目录先于 helper 删除、状态损坏、进程死亡、重试预算和开启取消。

完整生成的 shell 脚本会被执行，但电源命令/进程观察/等待等系统边界替换为测试实现，测试不修改本机休眠设置。真实合盖/断电/唤醒验收需在允许中断当前工作的情况下另行进行。
