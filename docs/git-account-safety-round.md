# Git 与账户额度安全优化

## PiMac

- 本地分支列表改为独立的可搜索选择器，多关键词匹配、自然排序、当前分支置顶；显示匹配数量，避免大型原生菜单难以查找。仍受 Server 返回前 200 个本地分支的限制。
- Git 操作确认改为独立审阅面板：展示捕获时的工作区、分支、目标分支、提交说明和完整文件列表，明确包含筛选外的已选文件。取消不会发出操作。
- 每次刷新尝试都会使旧确认失效。执行入口必须携带快照标识；过期确认、已消失的提交文件、无效相对路径以及未知方法不会发送到 Server。
- Git 操作执行及后续状态核对期间保持同一 busy 租约，阻止其他工作区刷新或第二个操作插入核对过程。网络失败不重试操作，必须显式成功刷新后才能继续。
- 只有执行成功且状态核对成功，才清空对应的提交说明／新分支输入；失败保留输入以便检查和恢复。
- 传输与操作状态机分离，生产 RPC 与竞态回归测试走同一条执行路径。分支选择器与操作确认从主 Git 视图中拆出。

**边界：**快照标识保护客户端确认，不锁定 Git 仓库，也不检查完整文件内容指纹。其他程序或后台 agent 仍可能在确认后修改文件或分支。实际执行、Git hooks、凭据和远端通信继续由 Server 负责。

## account-usage extension

- 账户身份解析独立到 `account-identity.ts`，供 HTTP 请求和额度缓存共同使用。
- 缓存键改为 provider、名称与 ChatGPT account ID 的摘要；没有可解析 ID 时保守地使用 access grant 的摘要。正常 token 刷新不会改变有稳定 ID 的账户身份，同名账户换绑会重新查询。磁盘缓存键不保存 ID 或 token 明文，旧缓存只失效，不迁移凭据。
- 查询结束后重新读取账户身份；变化时不发布旧额度、不预热旧账户。状态发布与自动轮换同样检查身份，不使用已换绑账户的本地额度。
- 新增 `/usage doctor`：仅查看认证托管状态、隐藏账户数量、额度快照新鲜度、刷新活动与 Gemini 快照状态。不请求网络、不发送预热消息、不切换账户，不展示原始 provider 错误或凭据。它是本地状态检查，不是实时连通性证明。

**边界：**进程间缓存仍按 provider 共用锁，不提供跨进程登录／身份变更事务。没有稳定 ID 的 grant 在刷新后会保守失效，可能需要再次查询。真实 OAuth 登录、端点权限以及真实额度耗尽需人工验证。

## 验证

`./scripts/check.sh` 已完整通过：230 个 Swift 测试、69 个 extension 测试、5 个设置迁移兼容测试、80 个 Server sidecar 测试，以及格式检查、extension 类型／lint／格式、旧 Fast extension 与真实 Pi RPC／codemode 本地兼容检查。测试没有调用远端付费模型。

环境仍输出已有 npm `q` 配置、nvm `npm_config_prefix` 与 Node SQLite 实验性提示，不影响本次测试通过。

新增回归覆盖：过期确认零发送、危险路径／缺失文件拒绝、未知操作拒绝、未确认结果不重试、状态核对租约、分支多词搜索、身份摘要及 token 更新、同名换绑缓存失效、查询中换绑拒绝发布、自动轮换拒绝旧身份额度、健康检查无网络／认证／会话写入副作用及敏感错误不输出。

人工 UI 验收：

1. 干净仓库打开 Git，搜索并选择本地分支，检查目标分支确认与取消行为。
2. 筛选文件后选择多个文件，检查提交审阅面板完整列出筛选外文件、提交说明和分支；取消后输入与选择保留。
3. 在确认期间触发外部状态刷新，确认按钮应锁定；关闭确认后重新检查状态。
4. 断开 Server 后不得执行 Git；已确认操作超时后不得自动重试。
5. Pi TUI／RPC 执行 `/usage doctor`，检查报告布局及未配置 Gemini、隐藏账户、失败快照提示。

不为 UI 人工验收、真实账户和 iPhone 验收作自动测试通过声明。
