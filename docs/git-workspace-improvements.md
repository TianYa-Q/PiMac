# Git 面板持续优化记录

## 本轮功能与 UI

- 工作区文件支持路径筛选：忽略大小写，空格分隔的关键词必须全部匹配；保留 Server 返回的文件顺序。
- “选择可见文件 / 取消选择可见文件”只影响筛选结果，不清除隐藏的选择。
- 显示可见文件数 / 总数；提交区域明确提示筛选外已选文件仍会提交，避免误以为只提交当前可见项。
- 无匹配结果提供独立空状态和清除筛选按钮。
- Git 状态读取失败使用独立错误空态，不再误显示“未发现 Git 仓库”。
- 差异预览支持原位重试；重试清除旧内容与截断标记，断连时禁用重试。
- 创建分支前校验常见 Git 分支名限制，显示具体错误并禁用无效操作。Server 仍负责最终校验和执行。

## 稳定性与重构

- 提取 `GitWorkspacePresentation`，集中管理筛选、选择与分支名规则。
- 刷新支持注入 RPC 传输，能够确定性测试旧请求与新工作区的竞争。
- 旧状态请求返回后立即检查刷新标识，不再继续请求过时工作区的分支。
- 非 Git 仓库不请求 refs，避免将正常的非仓库状态误判为刷新失败。
- 文件按路径去重并忽略空路径；分支去重排序，避免 SwiftUI 重复 identity。
- 刷新取消后禁止写操作并提示重新刷新；保留同工作区最后一次有效状态。
- 执行写操作前核对 payload 的 cwd 和当前仓库状态，阻止跨工作区 payload。
